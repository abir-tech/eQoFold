# Sequence provenance and data statement

## Data statement (challenge section 1.9)

**Every sequence in this repository is synthetic and computer-generated.**

No confidential Moderna data, no patient or clinical data, no proprietary
sequences, and no personally identifiable information are used anywhere in this
project. No sequence was obtained from a private source.

This is enforced in code, not only by policy:

- `RNASequence.__post_init__` rejects any record without an explicit `source`
  field, so a sequence of unknown origin cannot enter the pipeline silently.
- `tests/test_sequences.py::test_every_committed_sequence_is_public_or_synthetic`
  asserts that every committed sequence declares a `synthetic:` or `public:`
  source.

## How the sequences were produced

All four sets are generated deterministically by
`rnaqopt.sequences.generate_tier(tier, seed)` and regenerated by:

```bash
make sequences
```

Determinism comes from `random.Random` (Mersenne Twister), whose stream is
stable across CPython versions and platforms. Tier *k* uses
`GLOBAL_SEED + index(k)` with `GLOBAL_SEED = 20260807`.

Two tiers additionally apply an **acceptance screen** (rejection sampling): a
candidate is drawn, folded with ViennaRNA, and kept only if it satisfies a
structural predicate. Screening therefore depends on the pinned ViennaRNA
version (2.7.2); the committed FASTA files are the artifact of record, and CI
asserts that regeneration reproduces them byte-for-byte.

### What the screens do and do not select for

The screens select for **non-degeneracy of the benchmark instance**. They never
select for instances on which our model or our solvers perform well — that
would be benchmark rigging, and it would invalidate the encoding-gap
measurement that the whole project rests on.

Concretely: the first, unscreened draw produced **7 of 50 sequences whose MFE
structure was completely unpaired**. An empty reference structure is trivially
reproduced by any model (select no stems), so it consumes a benchmark slot
while contributing nothing to the encoding-gap or optimizer-gap measurements.
The screen removes exactly that pathology and nothing else.

### Tiers A, B, C

These are the size tiers of plan section 4.8. Tier A is small enough for
brute-force ground truth; Tier B is the main accuracy benchmark; Tier C is for
scaling studies only.

Tier A contains 8 **designed hairpins**: a random stem, its reverse complement,
an A/U-rich loop, and 0–2 nt flanks, with the stem length derived from a target
total length so every instance lands inside the tier range. These give
instances whose intended fold is known by construction and can be checked by
hand, rather than whatever a random sequence happens to do.

### Tier M — designed multiloops

Tier M is **not** in the original plan. It was added during Phase 1 in response
to a measurement, in the same spirit as the plan's separate pseudoknot set.

The plan's headline contribution is the Level 2 model, whose cubic terms exist
to represent the Turner **multiloop branch penalty** and coaxial stacking. That
contribution can only be measured on sequences that actually fold into
multiloops. The first generated corpus contained **one multiloop in 50
sequences** (Tier A: 0, Tier B: 0, Tier C: 1), which would have left the Level
1 → Level 2 gap closure unmeasurable.

A parameter sweep over closing-stem length, branch count, branch-stem length,
loop length and spacer width (20 draws per configuration, 44 configurations)
established that:

- **No configuration below 31 nt ever produced a multiloop MFE.** The Turner
  multiloop closing penalty (`a` ≈ +9.3 kcal/mol) cannot be repaid by the
  stacking energy available in that little sequence, at any GC content.
  Multiloops are therefore *thermodynamically unreachable* in Tier A
  (15–25 nt), not merely rare.
- Acceptance rates reach 17/20 at 36–38 nt with a 4–5 bp closing stem and
  4–5 bp branch stems.

Tier M uses the ten highest-yield geometries spanning 34–58 nt: seven 3-way
junctions and three 4-way junctions. Each candidate is accepted only when
ViennaRNA's MFE structure genuinely contains a multiloop, verified by
`rnaqopt.reference.has_multiloop`, which is itself cross-validated against
ViennaRNA's own loop decomposition (`eval_structure_verbose`) on all 60
sequences in `tests/test_reference.py`.

Tier M is also the only set that is simultaneously multiloop-bearing,
brute-forceable, and small enough in variable count to fit plausible Dirac-3
device limits. See `docs/ASSUMPTIONS.md`.

## Planned addition: public database sequences

The plan (section 4.8) calls for Tier B to draw on Rfam seed alignments or
RNA STRAND. That is **not yet done**, deliberately.

Recording an accession ID requires actually fetching the record; writing
plausible-looking accession numbers from memory into a graded provenance
document would be fabrication, and a wrong accession is worse than an honest
"synthetic only". The intended path is a `scripts/fetch_public.py` that
downloads from Rfam, records the real accession, alignment and release version
at fetch time, and appends verified entries to this file under a `public:`
source prefix. Until that runs, this corpus is 100 % synthetic — which is
explicitly permitted by challenge section 1.9.

## FASTA header format

```
>SEQ_ID | tier=X | source=... | notes=...
```

Fields are separated by `|`; each field splits on its **first** `=` only, so
values may themselves contain `=`. Neither `|` nor `>` may appear inside a
field value — both are rejected at construction time.
